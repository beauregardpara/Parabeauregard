# Version Windows 7

Cette édition est prévue pour **Windows 7 SP1 64 bits**.

1. Décompresser `ParaBeauregard-GestionVentes-Windows7-x64.zip`.
2. Double-cliquer sur `Installer-Windows7.bat`.
3. L’application est copiée dans `%LOCALAPPDATA%\ParaBeauregard` et un raccourci est créé sur le Bureau.

L’EXE est autonome : aucun runtime .NET ou autre composant ne doit être installé séparément. Windows 7 doit toutefois être à jour avec le Service Pack 1.

Cette version repose sur .NET 6, dernière génération .NET pouvant fonctionner sur Windows 7, mais cette plateforme est désormais hors support Microsoft.
